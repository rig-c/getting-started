# Getting started with rig-c

From one painting to a rigged character playing in your browser, for people setting it up for the first time.

This guide is being written. What it will cover:

- **What you need**: the painting, its layer decomposition, the joint positions, and what reads each one.
- **Making those inputs on your machine**: with an NVIDIA GPU, on an Apple Silicon Mac (slower, no NVIDIA GPU needed), or with no local GPU at all.
- **The rest runs on any computer**: installing the four packages and going from the inputs to a rig playing in a web page.

Every time, size and "it works" claim here will be measured on the machine it names.

The packages: [rig-c](https://github.com/rig-c/core) · [@rig-c/parts](https://github.com/rig-c/parts) · [@rig-c/pose](https://github.com/rig-c/pose) · [@rig-c/play](https://github.com/rig-c/play)
